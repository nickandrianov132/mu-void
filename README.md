# MU-VOID 🌌 
**Fullstack-платформа для MMORPG MU Online**

Профессиональный веб-портал, интегрированный с игровой экосистемой MU Online. Проект решает задачи автоматизации игровых процессов: от регистрации и рейтингов до сложных систем лояльности и приема платежей.

📍 **Live Demo:** [https://www.mu-void.com](https://www.mu-void.com)

---

## 🔥 Ключевые технические решения

### 1. Синхронизация серверного времени (Time Sync)
Реализован алгоритм компенсации разницы во времени между сервером (UTC-0) и клиентом.
*   **Проблема:** Рассинхрон локальных часов пользователя мешает точному отображению игровых ивентов.
*   **Решение:** При загрузке вычисляется `offset` (смещение) относительно серверного времени. Использование `setInterval` с очисткой (`cleanup function`) в React-хуках позволяет отображать точное время без утечек памяти.

### 2. Безопасность и работа с данными (MSSQL)
Взаимодействие с базой данных реализовано через пакет `mssql` с фокусом на безопасность:
*   **Защита от SQL-инъекций:** Использование параметризованных запросов (`.input()`) и вызов хранимых процедур.
*   **Бизнес-логика:** Реализована система покупки и конвертации VIP-статуса с динамическим пересчетом остаточной стоимости валюты.

### 3. Авторизация и State Management (RTK Query)
Централизованное управление состоянием и сетевыми запросами через **Redux Toolkit**:
*   **JWT Auth:** Автоматическая подстановка токена в заголовки через `prepareHeaders`.
*   **Reauth Interceptor:** Кастомный `baseQueryWithReauth` для обработки 401 ошибок и бесшовного логаута/обновления сессии.

## 🚀 Функционал
- **User Panel:** Управление персонажами, сброс характеристик (Reset/Grand Reset) с системой условий.
- **Rankings:** ТОП-100 игроков, владельцы замков и онлайн-статус, характеристики персонажа в реальном времени.
- **Monetization:** Интеграция платежных шлюзов **PayPal** и **CryptoCloud**.
- **Vote System:** Автоматическое начисление вознаграждения (WCoins) через систему Postback от игровых рейтингов.
- **Community:** Интеграция виджета Discord и динамические таймеры внутриигровых событий (Events).
- **Characters Equipment Decode:** декодировал бинарный массив данных инвенторя персонажа и передал конкретные зашитые в каждом байте данные о каждой вещи экипированной на персонажа на Front-end для последующей обработки и отрисовки.
- **Equipment Grid Layout** отрисовал Grid сетки для экипировки персонажа, Веб-ваулта и Веб-стора для размещения картинок-превью (png, jpg) вещей и размещения их в соответствующих столах согласно массиву бинарных данных т.е. что бы каждая вещь занимала позицию идентичную её размещения в самой игре по оси X и Y. А так же добавил Grid контейнеры для размещения вещей в них согласно их актуальным пропорциям (2х4, 4х4 и так далее) для удобства отрисовки в Market, Character Equipment что бы превью картинка вещи не выглядела не пропорциональной.
- **Tooltip for Item Preview** добавил React Tooltip для отображения информации о экипировке аналогично как это отображается в игре. 
- **Market:** Добавил Market в панель пользователя для улучшения внутриигровой торговли между игроками с возможностью продажи-покупки за 3 игровых валюты Zen, WCoin, GoblinPoint.
- **Back-End business logic** написал соответствующие функции в контроллерах для реализации взяимодействия игрока с игровыми данными - покупка, продажа, возврат, перевод валюты etc. Все это упаковал в SQL Транзакции для консистентности запроса и большей безопастности так как каждая оперция включает в себя несколько запросов к БД которые должны заверьшиться успешно либо откатить всю транзакцию.
- **Ancient Items Library** реализовал библиотеку древних вещей и отрисовку их опций согласно их категории, индексу, и рангу - динамически извлекаются соответствующие поля из заготовленных с помощью специальных парсеров (xml2js) .xml => JSON файлов и выводит их в Tooltip и грид сетке Ancient Items предварительно пропуская через вспомогательные функции.

## 🛠 Технологический стек

**Frontend:**
- React 18, React Router 6
- State: Redux Toolkit, RTK Query
- Styles: SCSS (модульная архитектура)
- Инструменты: Vite

**Backend:**
- Node.js, Express
- DB: MSSQL (Microsoft SQL Server)
- Auth: JWT (JSON Web Tokens)
